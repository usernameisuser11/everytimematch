# Everytime Match

상명대 학생을 대상으로 아이디어 검증을 해보기 위한 **간단한 캠퍼스 매칭 웹서비스 프로토타입**입니다.

## 현재 구현된 흐름

- 프로필 작성
  - 닉네임
  - 학년
  - MBTI 선택사항
  - 성별 / 찾는 상대
  - 한 줄 소개
  - Instagram 또는 카카오 오픈채팅 연락수단
- 상대 프로필 카드 보기
- 관심 있어요 / 넘기기
- 상호 관심 시 매칭
- 매칭 이후에만 연락수단 공개
- 신고 / 차단 데모
- 모바일 우선 UI
- localStorage 기반 프로필 임시 저장

## 실행

별도 설치 없이 `index.html`을 브라우저에서 열면 됩니다.

정적 사이트이므로 GitHub Pages, Render Static Site, Netlify, Vercel 등에 바로 올려 테스트할 수 있습니다.

## 데모 확인 방법

두 번째 데모 프로필인 **구름**은 상호 관심 상태로 설정되어 있습니다.

1. 프로필을 작성합니다.
2. 첫 번째 상대는 넘기거나 관심을 누릅니다.
3. 두 번째 상대에게 `관심 있어요`를 누릅니다.
4. 매칭 화면과 연락처 공개 흐름을 확인할 수 있습니다.

## 중요

현재 코드는 **의견 수집과 UI 검증을 위한 프론트엔드 프로토타입**입니다.

실제 서비스로 운영할 때는 아래 기능을 반드시 서버에서 구현해야 합니다.

- 학교 이메일 등 학생 인증
- 실제 계정 인증
- 프로필 / 좋아요 / 매칭 데이터베이스
- 연락처 접근 권한 제어
- 신고 및 차단 처리
- 개인정보 삭제
- 운영자 신고 검토 기능
- 악성 사용자 및 스팸 방지
- 개인정보 처리방침 / 이용약관

특히 연락처를 HTML이나 공개 API 응답에 미리 내려보낸 뒤 화면에서만 숨기는 방식은 안전하지 않습니다. 실제 서비스에서는 **매칭이 확인된 사용자에게만 서버가 연락처를 반환하도록** 설계해야 합니다.
